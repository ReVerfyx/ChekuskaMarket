# Steal An Egg: проверка игры и SpeedHubX (10 октября 2026)

Официальная страница: https://www.roblox.com/games/107778070777162/Steal-An-Egg . Игрок крадёт яйца у питомцев и других игроков, вылупляет питомцев, получает от них деньги, улучшает базу и беговую дорожку, тренирует Speed. Услуга «прокачка аккаунта» должна задавать проверяемую цель: например, значение Speed или уровень базы; нельзя считать запуск Lua достижением цели.

Исходник, который прислал владелец: https://github.com/LSSOPS/OpenSource/blob/main/SpeedHubX_Steal_An_Egg.lua . На момент просмотра файл содержит около 450 КБ / 14,8 тыс. строк. В интерфейсе есть независимые выключенные по умолчанию Auto Steal, Auto Place Egg, Auto Treadmill, Auto Hatch, Auto Upgrade Base и Auto Upgrade Treadmill. Auto Treadmill вызывает игровую логику с паузами; скрипт также загружает ещё два модуля с другого GitHub-репозитория (`AhmadV99/Main`) через `loadstring(game:HttpGet(...))()`. Это не API для запуска из Python на VPS. В коде есть Discord Webhook URL и функция сетевого запроса; без аудита зависимостей и проверки текущих файлов нельзя считать выполнение безопасным для игрового аккаунта.

`python3 extras/steal_an_egg_source.py` скачивает исходник отдельно от магазина, печатает SHA256 и ничего не запускает. В архив сторонний код без обнаруженной лицензии на перепубликацию не вложен. URL на ветку `main` изменяем; перед каждым использованием нужно проверять содержимое и зависимости.

У Ubuntu VPS нет запущенного клиента Roblox и совместимого исполнителя Lua. Готового моста, который запускает выбранные функции в игре, наблюдает прогресс конкретного аккаунта и закрывает сеанс, в проекте нет. Поэтому черновик услуги в `catalog.json` отключён (`enabled: false`), а `autoseller.py` публикует только доставляемые гайды.
