# Возврат при недоступной прокачке

Полного игрового исполнителя для Ubuntu в этой версии нет. Услуга прокачки выключена. Если поступит заказ с точным названием `Roblox Steal An Egg: прокачка Speed на дорожке`, бот сохраняет задачу возврата. Отдельный процесс `leveling_guard.py` проверяет продавца и название по странице заказа, снимает совпадающие лоты продавца с продажи и возвращает оплату заказа со статусом PAID. Другие товары не затрагиваются. Совпадение по названию требует сохранять это название на FunPay; заказы с другим названием не обрабатываются этим модулем.

## Запуск из установленного каталога

В `.env` нужны Golden Key и `DRY_RUN=0` для реальных действий. При `DRY_RUN=1` выводится только план.

В одном терминале:

```bash
.venv/bin/python bot.py run
```

Во втором:

```bash
.venv/bin/python leveling_guard.py
```

Для systemd приложен `funpay-leveling-guard.service`. Он предполагает проект `/opt/funpay-assistant`, пользователя `funpay` и доступ этого пользователя к каталогу `data`; пути и пользователя необходимо согласовать с вашей установкой.

Оба процесса должны работать. На одну базу допускается один процесс возвратов, это контролируется файловой блокировкой. После перезапуска незавершённые операции читаются из SQLite. Ошибка снятия лота не блокирует возврат. При потере ответа сначала запрашивается актуальный статус FunPay; повтор возможен не раньше 60 секунд. После трёх попыток возврата нужна ручная сверка, запросы возврата останавливаются. Снятие лота продолжает повторяться. Уже возвращённые заказы повторно не возвращаются.

Проверить состояние:

```bash
.venv/bin/python - <<'PY'
import bot
import leveling_guard
con = bot.database()
leveling_guard.initialize(con)
for row in con.execute('SELECT * FROM leveling_failures'):
    print(dict(row))
PY
```

Если FunPay недоступен, требует CAPTCHA или отклоняет действие, мгновенный возврат/снятие лота невозможны. Успех записывается только после проверки ответа сайта. Проверены 23 локальных теста, включая потерю ответа при возврате и независимую ошибку снятия лота. Реальные деньги и лоты здесь не менялись.
